# 🚀 GitGrade - AI-Powered Code Mentor

GitGrade is an intelligent tool that analyzes GitHub repositories to provide instant feedback, scoring, and actionable roadmaps for developers. Powered by **Google Gemini AI**.

## ✨ Features

* **📊 Repository Scoring:** Get a 0-100 score on code quality.
* **🤖 AI Code Analysis:** Uses Google Gemini 1.5 Flash to read and critique repo structures.
* **🗺️ Actionable Roadmap:** Generates step-by-step improvements for the codebase.
* **⚡ Instant Feedback:** Built with Next.js for high performance.

## 🛠️ Tech Stack

* **Framework:** Next.js 14 (App Router)
* **Language:** TypeScript
* **AI Model:** Google Gemini 1.5 Flash
* **Styling:** Tailwind CSS

## 🚀 Getting Started

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/gitgrade.git](https://github.com/your-username/gitgrade.git)
    cd gitgrade
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Set up Environment Variables:**
    Create a `.env.local` file in the root directory and add your Gemini API key:
    ```env
    GEMINI_API_KEY=your_api_key_here
    ```

4.  **Run the development server:**
    ```bash
    npm run dev
    ```

5.  Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
